# 模块映射表

| 任务书任务 | 实现位置 | 可检查内容 |
| --- | --- | --- |
| 文献调研与需求分析 | `evidence/参考文献.md`、`evidence/参考文献引用位置覆盖表.md`、`README.md` | 数据范围、目标、方法、参考资料 |
| 数据收集与预处理 | `data/al_data.csv`、`src/train.py`、网页“数据管理” | DOI、字段、单位、枚举清洗、排除字段、样本计数 |
| LightGBM 建模及特征选择 | `src/train.py`、`models/`、`feature_config.json`、`selection_report.csv` | 训练代码、特征选择、已训练主模型 |
| 模型评价与实验分析 | `metrics.json`、`shap_summary.csv`、`artifacts/figures/` | 三模型同划分指标、SHAP、8 张图 |
| 网页系统设计与实现 | `app.py`、`service/predict_service.py`、`service/sensitivity_service.py`、`service/comparison_service.py`、`api.py`、`theme.py`、`.streamlit/config.toml` | 八个页面、敏感性扫描、配方对比、共用预测服务、API、黄色主题 |
| 系统测试与材料整理 | `evidence/系统测试记录.md`、`evidence/运行说明.md`、`artifacts/screenshots/` | 测试结果和启动步骤；正式页面截图由用户后续补充 |

| 功能要求 | 实现位置 |
| --- | --- |
| 单条与批量预测、输入校验、导出 | `service/predict_service.py`、`app.py` |
| 训练预测字段顺序一致 | `feature_config.json`、`service/predict_service.py` |
| 新样本无标签不计算误差 | `app.py` 批量预测页 |
| 测试集隔离与同划分对比 | `src/train.py`、`metrics.json` |
| SQLite 查询、筛选、详情、导出、清空 | `service/predict_service.py`、`app.py` |
| 全局和局部 SHAP | `shap_summary.csv`、`app.py`、`api.py` |
| API 与网页调用同一服务 | `api.py`、`app.py` 均导入 `service.predict_service` |
| 依赖和运行说明 | `requirements.txt`、`README.md`、`evidence/运行说明.md` |
