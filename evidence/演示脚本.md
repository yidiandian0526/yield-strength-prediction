# 演示脚本

1. 启动项目并进入“数据管理”，展示 Mendeley Data V1 DOI、样本字段和单位说明。
2. 进入“模型与评价”，展示训练/测试样本数、MAE/RMSE/R²、特征筛选前后对比及图表。
3. 进入“单条预测”，点击“填入典型合金示例”或填写各元素含量，展示 MPa 预测值；选择元素查看补偿式敏感性曲线，并可点击“加入对比”。
4. 进入“批量预测”，上传含全部训练字段的 CSV 或 Excel，查看预测表并导出 CSV；确认没有真实标签时只生成预测列。
5. 进入“模型解释”，查看 SHAP 全局贡献和 Processing 分组误差，再生成一条输入的局部 SHAP 解释。
6. 进入“预测记录”，按模型筛选、打开一条详情并导出记录；演示结束后可清空记录库。
7. 进入“配方对比”，查看最多三组已计算配方的差异与最高预测值，下载 CSV 和 Markdown 报告；该页不写入预测记录库。
8. 进入“关于与说明”，展示字段/单位、动态模型指标、屈服强度分布、环境、启动方式、数据来源及模型适用范围。
9. 可选演示 API：打开 `/docs`，调用 `/health`、`/predict`、`/records`。
