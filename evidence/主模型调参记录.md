# 主模型调参记录

本次只在固定随机种子 2024 的训练子集内，以按成分组合分组的 3 折 GroupKFold 对 LightGBM 进行“单变量轮换的 11 候选局部搜索”。每折的 gain 特征选择器仅在该折训练部分拟合；166 条留出测试样本未参与选参。候选由基准组合及每个参数单独替换为一个备选值构成，选择依据为三折平均 MAE 最低，平局时标准差较低。

候选范围：

| 参数 | 候选值 |
| --- | --- |
| `num_leaves` | 31, 15 |
| `learning_rate` | 0.035, 0.06 |
| `n_estimators` | 700, 400 |
| `min_child_samples` | 12, 8 |
| `max_depth` | -1, 8 |
| `subsample` | 0.9, 0.8 |
| `colsample_bytree` | 0.9, 0.8 |
| `reg_alpha` | 0.05, 0.0 |
| `reg_lambda` | 0.2, 1.0 |
| `min_split_gain` | 0.0, 0.1 |

最终选择 `C04`，依据是三折平均 MAE 最低（39.473811 MPa，折间标准差 0.860289 MPa）。与基准配置相比，最终仅 `min_child_samples` 从 12 改为 8，其余候选参数保持基准值。最终参数：

```json
{
  "num_leaves": 31,
  "learning_rate": 0.035,
  "n_estimators": 700,
  "min_child_samples": 8,
  "max_depth": -1,
  "subsample": 0.9,
  "colsample_bytree": 0.9,
  "reg_alpha": 0.05,
  "reg_lambda": 0.2,
  "min_split_gain": 0.0
}
```
