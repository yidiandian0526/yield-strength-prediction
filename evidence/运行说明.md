# 运行说明

## 当前交付环境

执行环境为 Windows、Python 3.12。使用独立虚拟环境可安装 `requirements.txt` 中的依赖，不需要访问外部数据库或云端服务。交付目录已包含模型文件，正常启动网页无需重新训练。

## 启动

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

浏览器访问 Streamlit 启动时输出的本机地址。可选接口命令：

```powershell
uvicorn api:app --host 127.0.0.1 --port 8000
```

## 重新训练

仅当需要重建模型时，在项目根目录运行 `python src/train.py`。脚本只读 `data/al_data.csv`，输出模型、特征配置、评价、SHAP、8 张图及测试集预测表。若只需刷新示例 CSV 和证据摘要，可在已有训练产物基础上运行 `python src/refresh_delivery.py`；它不重训模型。

## 输入约定

批量输入包含 `Processing` 和 `feature_config.json` 的 `numeric_features` 中列出的全部成分字段，成分按百分比（0–100）填写。源 CSV 的成分值以 0–1 比例记录，训练预处理乘以 100；预测服务直接接收百分比，以保持训练与预测单位一致。多余字段会随结果保留，但不会进入模型；缺失、空值或非数字输入会报出可读错误。未知 Processing 状态会明确报错并列出允许枚举值；成分总和偏离 100% 超过 1 个百分点时显示警告但继续预测。无标签样本不计算 MAE、RMSE 或 R²。

## 测试与截图

`python src/verify_prediction_unit.py` 会真实运行 Streamlit AppTest、单条网页预测和本地 HTTP API，检查输入单位一致性并在测试结束后清空测试记录。`python src/verify_showcase.py` 会检查八页展示层依赖的补偿扫描、配方导出、外推标注、色板一致性和禁用词。正式八页截图由用户后续补充；本轮不重截或验收截图。模型训练指标和样本计数以 `metrics.json` 为准；系统测试结果见 `evidence/系统测试记录.md`。
