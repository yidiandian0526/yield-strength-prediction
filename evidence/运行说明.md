# 运行说明

## 当前交付环境

执行环境为 Windows、Python 3.12。使用独立虚拟环境可安装 `requirements.txt` 中的依赖，不需要访问外部数据库或云端服务。交付目录已包含模型文件，正常启动网页无需重新训练。

## 启动

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

浏览器访问 Streamlit 启动时输出的本机地址。可选接口命令：

```powershell
uvicorn api:app --host 127.0.0.1 --port 8000
```

## 重新训练

仅当需要重建模型时，在项目根目录运行 `python src/train.py`。脚本只读 `data/al_data.csv`，输出模型、特征配置、评价、SHAP、七张图及测试集预测表。

## 输入约定

批量输入包含 `Processing` 和 `feature_config.json` 的 `numeric_features` 中列出的全部成分字段，成分按百分比（0–100）填写。源 CSV 的成分值以 0–1 比例记录，训练预处理乘以 100；预测服务直接接收百分比，以保持训练与预测单位一致。多余字段会随结果保留，但不会进入模型；缺失、空值或非数字输入会报出可读错误。未知 Processing 状态以训练类别编码空间中的全零类别列参与预测。无标签样本不计算 MAE、RMSE 或 R²。
